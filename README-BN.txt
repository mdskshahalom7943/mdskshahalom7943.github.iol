MD SHAHALOM PERSONAL WEBSITE
বাংলা নির্দেশিকা

ফাইলগুলো:
- index.html  : ওয়েবসাইটের লেখা ও কাঠামো
- style.css   : রং, লেআউট ও মোবাইল ডিজাইন
- script.js   : বাংলা/ইংরেজি পরিবর্তন এবং সামাজিক লিংক
- README-BN.txt : এই নির্দেশিকা

মোবাইল দিয়ে GitHub Pages-এ প্রকাশ:
1. https://github.com/signup এ গিয়ে GitHub অ্যাকাউন্ট খুলুন এবং ইমেইল যাচাই করুন।
2. GitHub-এ লগইন করে + চিহ্ন বা New repository চাপুন।
3. Repository name দিন: আপনার GitHub username.github.io
   উদাহরণ: username যদি mdshahalom হয়, নাম হবে mdshahalom.github.io
   নামটি অবশ্যই আপনার আসল GitHub username-এর সঙ্গে মিলতে হবে।
4. Public নির্বাচন করে Create repository চাপুন।
5. Repository-তে Add file > Upload files নির্বাচন করুন।
6. ZIP ফাইলটি আগে ফোনে Extract/Unzip করুন। ZIP ফাইল নয়, ভেতরের index.html, style.css,
   script.js ফাইলগুলো সরাসরি repository-র root-এ আপলোড করুন।
7. Commit changes চাপুন।
8. Repository-র Settings > Pages খুলুন।
9. Build and deployment-এ Source হিসেবে Deploy from a branch নির্বাচন করুন।
10. Branch: main এবং folder: /(root) নির্বাচন করে Save চাপুন।
11. কিছুক্ষণ অপেক্ষা করে https://আপনার-username.github.io খুলুন।

সামাজিক লিংক বদলানো:
1. GitHub repository-তে script.js খুলুন।
2. Edit (পেন্সিল) চাপুন।
3. PROFILE_LINKS অংশে নিজের আসল YouTube, Facebook এবং WhatsApp লিংক বসান।
4. Commit changes চাপুন।
